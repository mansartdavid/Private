## 🎯 Objectif

Ce dépôt regroupe l'ensemble de mes notes, laboratoires, fiches de révision et glossaires réalisés durant ma formation :

> **Technicien Supérieur Systèmes et Réseaux (TSSR)**

L'objectif est de construire une base de connaissances durable permettant :

- d'apprendre les notions du REAC TSSR ;
- de documenter les laboratoires ;
- de centraliser les commandes et procédures ;
- de préparer l'examen final ;
- de constituer un portfolio technique professionnel.
